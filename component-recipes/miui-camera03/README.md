# camera03: external implementation

The accepted camera03 APK, its modified/decompiled implementation fragments and historical build recipe are retained in the local project delivery/evidence directories. They are not included in this Git history because a redistribution grant for the derived MIUI implementation has not been established.

This repository retains the integration build files, dependency names/hashes and a factual design description: a common CaptureRequest factory supplies the actual camera client identity consistently; an older aperture-setter-only workaround is retired. This description is not the complete application source or a license to redistribute Xiaomi software.

Keep using the accepted external camera03 payload for the existing build. Do not substitute generated or older APKs. See artifacts/binary-dependencies.json, provenance/accepted-source-files.json and docs/LICENSE_AND_DISTRIBUTION.md.
